# Projects

## 1. Audio Noise Cancellation using Wiener Filter

### Overview

This project implements an optimal Wiener Filter to remove additive white Gaussian noise from speech signals while preserving useful information.

### Concepts

- Wiener Filter
- PSD Estimation
- Welch Method
- FFT
- Spectrogram
- Signal Enhancement
- SNR Improvement

### Tools

- MATLAB
- Signal Processing Toolbox

---

## 2. Verification of the Power Spectral Density Properties

### Overview

This project verifies two fundamental properties of the Power Spectral Density (PSD):

- Non-Negativity
- Even Symmetry

using

- Wiener–Khinchin Theorem
- Analytical Derivation
- MATLAB Simulation
- FFT Periodogram

### Concepts

- Wide Sense Stationary Process
- Autocorrelation Function
- PSD
- Fourier Transform
- FFT
- Lorentzian Spectrum
